## Selected Projects

**Brain CT Pathology Classification via SSL**
Two-stage pipeline combining SwinUNETR Masked Autoencoding 
(3D volumetric pretraining) with SimCLR, BYOL, and Barlow 
Twins at slice level, fine-tuned with Multiple Instance 
Learning. 155 controlled experiments on 500 clinical patients. 
Binary decomposition improved minority-class AUC by 6–41% 
over joint multi-label baselines.

**CR-MEMO: Consistency-Regularised Test-Time Adaptation**
Extension of MEMO (NeurIPS 2022) with a KL-divergence 
consistency term across augmented test views. +9.12% accuracy 
on ImageNet-V2 distribution shift. Open source.

**Financial Trade Anomaly Detection**
Isolation Forest and XGBoost ensemble for fraud detection at 
0.17% positive rate. XGBoost PR-AUC 0.876, ensemble precision 
0.952. SHAP explainability included. Production-grade 
codebase with pytest suite and model card.

**Maritime Satellite IoT Link Quality Prediction**
Multimodal fusion of AIS telemetry, ERA5 weather reanalysis, 
and satellite geometry via multi-head attention. Four 
architectures benchmarked. 89% balanced accuracy under 3% 
minority-class imbalance.
